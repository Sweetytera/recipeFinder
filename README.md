# 🍳 Recipe Finder

A responsive web application that helps users discover recipes based on the ingredients they have. Users can search for recipes, explore random suggestions, and view complete recipe details including ingredients, images, and cooking instructions.

## 🚀 Features

* 🔍 Search recipes by ingredient
* 🍽️ Display recipe suggestions
* 🎲 Explore random recipes
* 📖 View complete recipe details
* 🥕 View ingredients and cooking instructions
* 📱 Responsive design for different screen sizes
* ⚡ Fast and interactive user interface

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite
* **Styling:** Tailwind CSS
* **API:** TheMealDB API
* **Deployment:** Vercel
* **Version Control:** Git, GitHub

## 🔄 How It Works

1. The user enters an ingredient in the search bar.
2. The React application sends a request to TheMealDB API.
3. The API returns recipes matching the ingredient.
4. The application displays the available recipes.
5. The user can select a recipe to view its complete details.
6. Recipe details include the image, ingredients, and cooking instructions.

## 🔌 API Integration

The application uses **TheMealDB API** to retrieve recipe information.

The API is used for:

* Searching recipes based on ingredients
* Retrieving complete recipe information
* Displaying recipe images and instructions

No API key is required for the API endpoints used in this project.
